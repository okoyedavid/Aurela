The source pages explicitly permit use, modification and redistribution, including commercial use. Source files were obtained October 24, 2026. The download URL for each is `https://www.innerscene.com/api/library/<page-slug>/download`. Save them as `.local/models/harper-source.glb`, `sam-source.glb` and `riley-source.glb` to reproduce.

Aurela modifications: simplified geometry; removed hidden teeth; normalized height; neutralized garment textures for recoloring; resized and compressed textures to WebP; compressed geometry with meshoptimizer. Riley's trousers are replaced by an original draped skirt paired with the source's fitted top. These outfits are illustrative, not scans of the listed products.

See manifest.json for measured sizes and triangle counts. Run `npm run models:prepare` to reproduce the assets with `features/runway/scripts/prepare-models.mjs`.
